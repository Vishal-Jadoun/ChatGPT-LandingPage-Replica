# ChatGPT Replica

A beginner-friendly frontend clone of the ChatGPT interface built with React.

## Current Progress
- 🟢 **Sidebar**: Fully prepared and functional with simple emoji icons and a collapsible toggle.
- 🟢 **Layout**: Main layout structure created with a top bar.

## Future Plans
- 🚧 **Local LLM Integration**: The plan is to connect this frontend to a local Large Language Model (LLM) in the future, allowing it to function as a fully working AI chat application right from the local environment.

## Technologies Used
- React (Vite)
- Standard CSS (No complex frameworks)
- Simple HTML elements and emojis for beginner-friendly code structure

## How to Run
1. Make sure you have Node.js installed.
2. Clone this repository.
3. Run `npm install` to install dependencies.
4. Run `npm run dev` to start the local development server.
